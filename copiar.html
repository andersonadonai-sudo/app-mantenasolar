Como publicar no celular

1

Toque no botão laranja acima. Vai virar verde escrito “COPIADO”. O código inteiro (39 mil caracteres) vai para a área de transferência do celular.

2

Abra o Apps Script no navegador do celular. Use o link abaixo. Se pedir para escolher conta, use a mesma do Google Drive da Mantena.

3

Abra o arquivo Código.gs na lista da esquerda. Se começar com a letra C. Se tiver outro arquivo .gs, este é o certo.

4

Apague TUDO que está lá dentro. Toque dentro do código, segure, faça “Selecionar tudo” → apagar. A tela tem que ficar vazia.

5

Cole. Toque, segure e escolha Colar. Vai aparecer muito código. Espere terminar de carregar.

6

Salve. Toque no ícone de disquete 💾 no topo. Aparece “Salvo” embaixo.

7

Implante uma versão nova. Ícone azul Implantar → Gerenciar implantações → lápis ✎️ da lista → em Versão escolha Nova versão → Implantar.

8

Abra o app. Use o link azul abaixo. Se ainda mostrar erro, puxe a página para baixo para recarregar.
